## 隐私政策

本网站是个人学术主页，不提供用户账户、评论、广告或支付表单。

### 访问分析

{% if site.analytics.provider == "self-hosted" %}
本站使用独立部署的访问统计服务，记录页面访问、服务端时间、来源网站域名、推广参数、概略设备和浏览器类型、浏览器语言，以及匿名浏览器和会话标识。若配置离线地理数据库，还会记录近似国家、地区和城市。统计数据库不保存原始 IP 地址、完整 User-Agent、推广参数以外的 URL 查询字符串或 URL 片段。详细记录只允许管理员登录统计面板后查看。

浏览器保存一个最长使用一年的随机标识，并在 30 分钟无页面访问后重建会话标识。这些标识用于估算浏览器数量，不能识别真实人数。本站尊重 Do Not Track 和 Global Privacy Control。您可以[关闭此浏览器的访问统计](/zh/terms/?analytics=off)，或[重新启用](/zh/terms/?analytics=on)。关闭后会删除浏览器中的统计标识；浏览器存储可用时，该偏好会持续阻止采集。退出统计不会删除已保存的服务端记录。记录由网站所有者管理和删除，目前不设置自动保留期限。
{% else %}
本站使用 GoatCounter 汇总访问流量统计。分析脚本在 `_config.yml` 中配置；在本地开发环境中，可通过 `_config.dev.yml` 将其禁用。
{% endif %}

主页可能会展示一幅同步汇总统计、按国家或地区呈现的访客地图。自托管地图使用页面访问次数，去重浏览器数仅在私人统计面板中查看。该地图不会显示访客姓名、IP 地址、城市、精确位置或会话数据。汇总访问量低于地图最低显示阈值的国家或地区不会显示。

交互式地图会从 esm.sh 加载锁定版本的地理渲染模块，因此访客的浏览器也可能向该内容分发网络发送请求。
