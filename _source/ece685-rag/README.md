## 准备和合并

在已安装 `scripts/requirements-ece685-rag.txt` 的 Python 环境中运行：

```sh
python3 scripts/import_ece685_chat_references.py
python3 scripts/export_ece685_chat_corpus.py --references tmp/ece685-chat/references/<reference-version>
```

导入器检查文件哈希、页数、身份信息、教材版本和页面范围，从 PDF 书签取得章节，区分印刷页码、PDF 页标签与 PDF 实际页码。当前教材的页标签与印刷页对应；报告的标签可能把无编号封面编号为 1，因此仅保留其 PDF 页标签，不把它猜成印刷页号。跨小节的同一物理页可记录多个小节，不假定书签能给出精确的段落边界。语料稳定 ID 例如 `ECE685:reference:glover-6e-2017:page:0061`，人工核验说明则使用独立 `verified` ID。

每个参考版本产生：

- `references.jsonl`：允许进入检索的记录。
- `quarantine.jsonl`：字体损坏或异常字形等待处理记录，保留供复核，不上传。
- `quality-report.json`：611 页导入覆盖、逐页问题、教材选择、其他材料缺口和来源统计。
- `manifest.json`：参考版本与记录/报告哈希；合并器先校验完整性。

## 检索时的来源选择

- 平台教材依据：使用平台选择说明，按第 6 版准备；若问 syllabus 原文，说明它仍列第 7 版。后续服务按 manifest 读取选择说明并作为课程级上下文传入，不依赖每次检索恰好命中该记录。
- 课程要求、日期、成绩构成及 AI 政策：优先使用 Fall 2026 syllabus；回答要说明依据的学期，课程后续公告另行同步。平台教材选择不覆盖其他政策。
- 当前讲的符号、约定和例题：使用该讲原课件与网页说明；教材补充推导，并明确不同记号、基准或版本。
- 练习题：默认采用第 6 版的实际题目；学生明确指定其他版次时，要求同版题文。题文缺失、隔离或尚未核验时应请求原题，不凭同题号或版次兼容字段猜测内容。
- 成本数据：引用原报告年份、金额基年、单位和假设；不拼接不同报告的数字成为一个无来源的新表。
- 字体失真的公式页：读取待复核数据不能直接成为模型上下文；使用核验说明或原图核验后再解除隔离。
